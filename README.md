# Wazi

Verified property intelligence for Tanzania. Interactive MVP demo for TAREX 2026.

- Verify a property: score, five checks, price check, seller trust rating
- Notifications, WhatsApp message preview and feedback prompt
- English and Swahili

The six records are illustrative samples in Dar es Salaam, Dodoma and Kilimanjaro. They are not real land registry results.
